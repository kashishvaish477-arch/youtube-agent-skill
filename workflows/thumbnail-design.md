YouTube Thumbnail Design Workflow

Purpose

Create original, visually appealing YouTube thumbnail concepts that communicate the video's topic and attract the target audience.

Step 1: Understand the Video

Identify:

- Video topic
- Target audience
- Main video message
- Preferred visual style
- Video title
- Intended audience emotion or curiosity

Ask only for essential missing information.

Step 2: Analyze the Thumbnail Concept

Identify:

- Main visual subject
- Supporting visual elements
- Background
- Main emotion or visual message
- Key point viewers should understand immediately

Step 3: Generate Three Thumbnail Concepts

For each concept provide:

- Concept name
- Main subject
- Background design
- Composition
- Color direction
- Lighting
- Facial expression, if relevant
- Thumbnail text (2–5 words maximum)
- Text placement
- Unique visual element

Step 4: Evaluate Concepts

Score each concept from 1 to 10 for:

- Visual clarity
- Topic relevance
- Originality
- Readability on mobile
- Audience appeal

Scores are editorial estimates, not predictions of click-through rate.

Recommend the strongest concept and explain why.

Step 5: Create Image Generation Prompts

For the recommended concept, create a detailed image-generation prompt.

Include:

- Main subject and appearance
- Background
- Composition
- Lighting
- Color palette
- Camera angle
- Visual style
- Space for thumbnail text
- YouTube thumbnail aspect ratio of 16:9

Avoid unnecessary visual clutter.

Do not imitate another creator's exact thumbnail.

Step 6: Thumbnail Design Rules

- Communicate one main idea.
- Use short, readable text.
- Make the subject recognizable.
- Use strong visual contrast.
- Avoid excessive elements.
- Ensure important details remain visible on mobile.
- Keep the thumbnail consistent with the actual video.
- Use original or properly licensed images.

Step 7: Image Generation

When image-generation tools are available:

- Generate an image when explicitly requested.
- Follow the selected concept.
- Preserve the video's intended message.
- Do not claim an image was generated unless the tool confirms success.

Step 8: Final Quality Check

Check:

- Is the thumbnail relevant?
- Is the main subject clear?
- Is the text readable?
- Is the design original?
- Does it accurately represent the video?
- Does it work at small screen sizes?

Final Output

Return:

1. Three thumbnail concepts.
2. Evaluation scores.
3. Recommended concept.
4. Thumbnail text.
5. Detailed image-generation prompt.
6. Design and composition instructions.
7. Final quality checklist.

End by asking: "Would you like to generate this thumbnail or change the concept?"
